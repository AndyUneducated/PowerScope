## ⚡ PowerScope 1.0.1

A full pass over every place the app shows charger data, fixing values that came from a charger that is no longer connected.

### 🐛 Fixes
- 🔌 **Ports showed every USB-C port as in use.** macOS leaves a disconnected charger's power-source entry on a port, still marked in use but no longer registered. A port now counts as in use only when its source is live; cached entries are shown as "Not connected".
- 🎛️ **Port controllers listed old chargers as if present.** A controller keeps the PDOs and request of its last charger after it is unplugged. Controllers now show a status (Supplying, Connected, Not connected) from their PD state and source types, and cached data is greyed out and marked "cached".
- 🧭 **A disconnected controller could become the contract.** The contract resolver now only considers controllers with a charger attached, so a leftover power budget or matching PDO on a cached controller can no longer win.
- 🔋 **No contract on battery.** Without external power the app no longer reports a PD contract, in the contract card, the menu bar or the history.
- ✅ **False "negotiated vs elected source" warning.** The cross-check now only uses live sources.

### ✔️ Checked and unchanged
- Adapter details, IOPowerSources adapter info, PMU input setpoint and charger data all refresh to the connected charger.

### 🧪 Tests
- 9 new tests replay the reported case: a 100 W charger on controller 2 while controllers 0 and 1 hold cached 94 W and 140 W data (53 tests in total). The key tests were confirmed to fail without the fixes.

### 📦 Install
1. Download `PowerScope-v1.0.1.zip` and unzip it
2. Move `PowerScope.app` to `/Applications`
3. Clear the download quarantine once: `xattr -dr com.apple.quarantine /Applications/PowerScope.app`
